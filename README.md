# Cave Regale — Organized Website Prototype

This package is a **client-review prototype** for the Cave Regale hotel website.

## Prototype pages
- Home
- Accommodation
- Dining
- Experiences
- Heritage & Story
- Gallery
- Location & Contact

## Deliberately excluded from this prototype
- Guest login / registration
- My Bookings
- Online booking engine
- Payment / OTA / PMS integrations
- Separate duplicate room/landing pages

Those features were removed because the agreed website scope is a simple hotel marketing website. The prototype focuses on the visual direction, content structure, responsive layout, and client feedback before Laravel development.

## How to review
Open `index.html` in a browser and use the navigation. All internal prototype pages are linked from the main navigation.

## Next step
Get client approval on layout, typography, colors, imagery, sections, and page structure before converting the approved design into the Laravel/Tailwind implementation.
